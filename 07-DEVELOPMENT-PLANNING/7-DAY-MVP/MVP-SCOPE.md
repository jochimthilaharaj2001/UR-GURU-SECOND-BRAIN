# MVP Scope — Blueprint source summary

Source: Blueprint pages 1–7. Selected capabilities span authentication, curriculum, teacher approval/discovery, classes/batches/enrollment, optional free demos, live sessions, payments, materials, XACT, assignments, notifications, admin, safety and subject forum.

## P0 integrated journey
Student/teacher identity → teacher approval → discover class/batch → server price and capacity → verified sandbox payment → exactly one enrollment → protected access. Basic XACT practice only when Exam Munnodi integration and rights permit.

## P1 breadth
Timed mocks, assignments, attendance, finance operations, moderation, notifications, support and community.

## Explicit non-scope for seven-day plan
Student NIC, MFA feature, guardian dashboard, other streams, teacher ratings/set prices, live class recording, direct private messaging, local XACT question authoring, automated payouts and live trial booking.

## Caveat
These are **seven-day blueprint exclusions**, not automatic changes to BRD v6.2.2. See `DECISION-CONFLICTS.md`.
