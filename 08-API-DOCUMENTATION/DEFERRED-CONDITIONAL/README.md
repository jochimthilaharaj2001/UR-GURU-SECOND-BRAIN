# Deferred / Conditional APIs

Project planning refers to **52 deferred/conditional APIs**, but the provided MVP workbook contains only `MVP APIs` (292) and `Post MVP Current` (177) endpoint lists. No authoritative list of the 52 endpoints is included in this source.

Do not invent endpoint names, HTTP methods, DTOs or owners. Obtain the approved full-scope API tracker, then create a separate versioned index. BRD v6.2.2 later/conditional areas include transcription, teacher-reviewed AI revision notes, AI study assistance, ExamPilot, DataSmart and institutions, each subject to separate consent, feasibility, human review and budget decisions. Future features are not necessarily all in the 52 count.
