# Git Branching and PR Policy

**Status:** Draft for DEV_2 approval; GitHub protection must be configured separately.

- Default branch: `main` (protected once configured).
- Work in `feature/<ticket>`, `fix/<ticket>`, or `docs/<ticket>` branches.
- Use PRs with summary, affected BR IDs, API/schema/UI impact, test evidence and rollback considerations.
- Controlled Second Brain documents require DEV_1 review and approval before merge.
- `19-CHAT-MEMORY/` is excluded from the DEV_2-only document rule; developers maintain their own folders.
- No secrets or private identity records in commits.
- Follow [Document Access Control Policy](DOCUMENT-ACCESS-CONTROL-POLICY.md).
